# My Online Book Store

## About the Project

My Online Book Store is a basic website created as a college project using HTML and CSS. The main purpose of this project is to display books from different genres in an organized way so visitors can explore the available books and read their details.

## Book Categories

The website includes the following categories:

* Technology
* Education
* Fiction
* Non-Fiction
* Mystery

Each category contains books with details such as the title, author, price, description, and book cover image.

## Technologies Used

* **HTML:** Used to create the structure and content of the website.
* **CSS:** Used to style the webpage and improve its appearance.

## Features

* Simple and easy-to-understand layout
* Different book categories
* Book titles, authors, prices, and descriptions
* Book cover images
* Contact section with a message form

## How to View the Project

1. Open the project repository on GitHub.
2. Download the project files or clone the repository.
3. Open the `index.html` file in a web browser.

## Learning Experience

While making this project, I practised the HTML and CSS concepts I learned in college and through YouTube tutorials. It helped me understand how webpages are structured and how CSS can be used to style them.

## Note

This is a basic static website created for learning purposes. Features such as online payments, user accounts, and actual book ordering are not included.
